# 软件需求规格说明书（SRS）

## 一、引言

### 1.1 编写目的

本软件需求规格说明书旨在详细描述“智慧植物灌溉与监控系统”的功能需求、非功能需求、运行环境、用户特性以及系统设计约束，为后续系统设计、开发、测试与维护提供规范依据，并作为甲乙双方沟通的重要文档基础。

### 1.2 项目背景

该系统聚焦智慧农业与家庭园艺领域，结合嵌入式采集、边缘计算与强化学习，构建一套软硬件协同、自主优化灌溉策略的智能系统。系统用户涵盖普通植物养护者、农业研究者及系统运维者，平台需兼容数据感知、AI控制、交互反馈与远程管理等多重场景。

## 二、总体描述

### 2.1 产品功能概述

系统整体包括以下核心功能模块：

- **环境数据采集模块**：周期性采集温度、湿度、土壤湿度、光照、水位与供电电量信息；
- **本地交互模块**：支持 OLED 显示、LED 指示灯、语音交互与按钮控制；
- **数据传输模块**：将采集数据上传至服务器与树莓派，并接收命令反馈；
- **智能决策模块**：强化学习模型基于历史数据优化灌溉策略，动态调整阈值；
- **远程控制模块**：用户通过 Web 界面实时查看植物状态，手动控制灌溉与参数配置；
- **可视化与推荐模块**：展示趋势图表，生成养护建议，推动社区内容互动。

### 2.2 用户特性

| 用户类型   | 特征                   | 权限描述                                      |
| ---------- | ---------------------- | --------------------------------------------- |
| 普通用户   | 植物爱好者、家庭养护者 | 可绑定设备、查看状态、发送控制指令、参与论坛  |
| 管理员     | 系统管理人员、教师     | 可管理用户与数据、审核内容、部署模型          |
| AI决策模块 | 算法系统               | 基于数据生成阈值策略，向ESP32推送参数调整命令 |

### 2.3 假设与依赖

- 假设设备始终处于联网状态，且传感器工作正常；
- 项目基于学校支持的软硬件资源与网络环境部署；
- 强化学习模型初期通过模拟数据训练，后期逐步替换为真实数据；

## 三、功能需求

### 3.1 环境数据采集

- 每隔指定时间（默认5秒）由 STM32 自动采集环境参数并打包发送至 ESP32。
- 数据包括：温度（℃）、湿度（%）、土壤湿度（%）、光照强度（Lux）、水位状态、电量（%）。

### 3.2 数据中继与封装（ESP32）

- 接收 STM32 数据串口信息；
- 封装为 JSON 格式并上传至树莓派与 Web 服务器；
- 接收下行命令（如阈值更新、控制信号）并转发至 STM32。

### 3.3 状态显示与本地交互

- OLED 屏幕切换显示模式：默认展示植物信息与状态、AI 聆听、浇水中、低电警告；
- LED 灯带根据电量、水位进行实时反馈（颜色与亮度编码）；
- 支持按钮点击与语音唤醒切换控制模式；
- 通过语音识别与合成，完成与用户的基本问答（如“你今天好吗”“我需要喝水吗”）。

### 3.4 AI 决策与策略优化（树莓派）

- 持续接收环境数据并存储为本地日志；
- 使用 Q-Learning 或 DQN 模型，根据数据调整土壤湿度上下限；
- 周期性推送阈值 JSON 数据至 ESP32；
- 支持在线更新模型参数与策略切换接口。

### 3.5 Web 平台功能

- 用户注册/登录，设备绑定与个人主页展示；
- 实时展示设备状态（数字/图表）、历史趋势图（ECharts）；
- 远程控制界面：一键浇水、模式切换、设置阈值；
- 社区论坛支持发帖、评论、点赞；
- AI推荐模块输出植物养护建议、推荐植物新品种。

## 四、非功能性需求

### 4.1 可靠性

- 系统应在传感器脱落、设备重启等异常情况下自恢复；
- 数据包传输必须具备丢包重发与校验机制；

### 4.2 可用性

- 用户界面应简洁直观，图形反馈及时准确；
- 支持 PC 端与移动端自适应页面加载；

### 4.3 可扩展性

- 支持多个植物设备接入（通过 plant_id 区分）；
- 模块应具备横向拓展能力，如引入 CO₂/图像识别模块不影响原有逻辑；

### 4.4 安全性

- 用户登录与操作采用 Token 鉴权机制；
- 后台访问路径受权限控制，管理操作记录操作日志；

## 五、接口需求（摘要）

| 接口名称     | 方法 | 路径                              | 描述                      |
| ------------ | ---- | --------------------------------- | ------------------------- |
| 上传环境数据 | POST | `/api/plant/data`                 | 上传一条 JSON 数据包      |
| 获取实时状态 | GET  | `/api/plant/:id/status`           | 查询当前植物传感器数据    |
| 发送控制命令 | POST | `/api/control/send`               | 向设备发送浇水/模式命令   |
| 推送AI阈值   | POST | `/api/ai/update-threshold`        | 树莓派向ESP32传递更新策略 |
| 获取历史数据 | GET  | `/api/plant/:id/history?range=7d` | 获取指定范围内历史数据    |

## 六、运行环境

| 组件     | 描述                                 |
| -------- | ------------------------------------ |
| 设备端   | STM32、ESP32（使用 FreeRTOS + UART） |
| 边缘端   | Raspberry Pi 4（Raspbian + Python）  |
| 服务端   | Ubuntu Server + Flask + MySQL        |
| 前端环境 | Vue.js + ECharts + Axios + Bootstrap |
| 通信协议 | JSON over UART / MQTT / HTTP         |
