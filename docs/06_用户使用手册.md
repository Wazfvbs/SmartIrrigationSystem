# 智慧植物灌溉系统用户使用手册

## 一、文档目的

本手册旨在为终端用户提供全面的操作指引，确保用户能够正确、安全、高效地使用“智慧植物灌溉与监控系统”，充分发挥系统在植物养护、远程监控、节水管理等方面的功能价值。适用于初学者、普通用户及维护人员。

## 二、系统简介

智慧植物灌溉系统集成了 STM32 控制模块、ESP32 中继模块、树莓派 AI 决策模块与 Web 前后端远程控制平台，具备以下特点：

- 🌱 实时采集温度、湿度、光照等多源环境数据；
- 🧠 结合 AI 强化学习模型自动生成灌溉策略；
- 🌐 远程 Web 平台实时控制与图表可视化；
- 🗣️ 语音交互控制与多模式 LED 显示反馈；
- 🔄 本地自动与远程手动控制自由切换。

## 三、系统组成与功能概览

| 组成模块 | 功能说明                                |
| -------- | --------------------------------------- |
| STM32    | 传感器数据采集、水泵控制、数据打包      |
| ESP32    | 模式控制、OLED 显示、语音识别、中继通信 |
| 树莓派   | AI 策略推理、数据存储、模型更新         |
| Web 平台 | 用户界面、设备管理、图表展示、参数设置  |

## 四、快速开始

### 4.1 系统初始化流程

```
1. 接通设备电源
2. STM32 启动并初始化传感器
3. ESP32 启动，OLED 显示系统状态
4. 树莓派载入强化学习模型
5. Web 页面连接设备并开始展示数据
```

### 4.2 登录 Web 平台

1. 使用浏览器访问 `http://<服务器IP>:5000`
2. 注册账号或使用管理员账号登录
3. 进入控制台 Dashboard 查看植物状态

### 4.3 数据查看与控制操作

- 实时监控：查看当前湿度、温度、光照
- 历史记录：选择时间区间，展示折线图
- 手动浇水：点击“立即浇水”按钮触发
- 修改策略：在“策略设置”中手动输入 AI 阈值

## 五、常见操作流程

### 5.1 查看植物状态

- 打开“控制台”→ 查看当前采集数据与环境指数
- OLED 端同步显示温湿度等信息

### 5.2 执行浇水操作

- 方法 1：点击 Web 控制台上的“立即浇水”按钮
- 方法 2：对 ESP32 麦克风说出“我要浇水”

### 5.3 策略管理

- Web → 策略设置 → 选择“AI模式”或“手动模式”
- 手动输入湿度阈值范围（如：35 ~ 60）并保存

### 5.4 多设备绑定

- 管理员进入“用户中心” → 添加新设备编号
- 每个账号支持绑定多株植物与不同终端

## 六、界面导航说明

### 6.1 控制台界面

- 当前状态面板（湿度、温度、光照）
- 策略状态：当前策略来源（AI/手动）、阈值
- 历史记录图：可选择时段与指标展示曲线

### 6.2 用户中心

- 修改密码、绑定设备、设置权限
- 下载数据报表（.csv/.xlsx 格式）

### 6.3 策略设置页

- 查看模型版本、上传 JSON 策略
- 接收来自树莓派的新推荐策略

## 七、常见问题与解决方案（FAQ）

| 问题               | 可能原因                   | 解决方案                            |
| ------------------ | -------------------------- | ----------------------------------- |
| 页面无法访问       | 网络断开或后端未启动       | 检查 WIFI 与服务器是否开启          |
| 浇水无响应         | 阈值设置不合理或数据未上传 | 检查 soil_moisture 值与策略是否匹配 |
| OLED 显示乱码      | 模块供电不足               | 使用 5V 稳定电源供电                |
| 麦克风无法识别语音 | 环境噪音过大或麦克风损坏   | 换安静环境或更换麦克风模块          |

## 八、安全与使用规范

- 禁止用水泵连续浇水超过 2 分钟，防止电机过热；
- 请勿暴露设备在强阳光、雨水或尘土中；
- 每月检查一次水箱水位，清洗传感器外壳；
- 策略上传前务必验证 JSON 格式正确；
- 管理员权限操作需妥善保管账户密码；
