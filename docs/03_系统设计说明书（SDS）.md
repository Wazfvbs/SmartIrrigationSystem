## 二、系统总体设计

### 2.1 系统结构概览

系统采用“采集-中继-学习-控制”四层结构模式：

```
用户界面层（Web平台 + OLED显示 + LED + 语音）
        ↑
学习与策略层（树莓派强化学习模型）
        ↑
中继交互层（ESP32，语音控制 + 状态显示 + 数据中继）
        ↑
采集控制层（STM32，传感器驱动 + 水泵控制）
```

## 三、模块设计说明

### 3.1 STM32 传感控制模块

- **功能职责**：
  - 驱动并读取温湿度、土壤湿度、水位、光照、电量传感器；
  - 控制水泵灌溉逻辑；
  - 接收来自 ESP32 的灌溉控制命令；
- **关键实现**：
  - 使用中断方式定时采集数据；
  - UART 串口协议发送数据帧至 ESP32；

### 3.2 ESP32 中继与交互模块

- **功能职责**：
  - 将 STM32 数据上传至服务器/树莓派；
  - OLED 显示：状态模式、温度湿度等轮播信息；
  - LED 灯带：不同颜色表示不同状态；
  - 语音识别：本地识别或联动 OpenAI 接口完成语音交互；
- **关键实现**：
  - FreeRTOS 多任务并发：分为数据传输、交互控制、语音管理等任务；
  - JSON 封装上传格式；

### 3.3 树莓派 AI 控制模块

- **功能职责**：
  - 接收环境数据，训练强化学习模型（Q-learning/DQN）；
  - 动态调整灌溉阈值参数并下发给 ESP32；
  - 存储设备运行历史数据、模型日志；
- **关键实现**：
  - 训练环境模拟器（Gym 环境）与实测数据映射；
  - 使用 PyTorch 实现策略网络；

### 3.4 Web 前后端系统

- **前端功能**：
  - 展示实时/历史环境数据（图表）、灌溉记录；
  - 用户设备管理、社区交流模块；
  - 控制指令发送界面；
- **后端功能**：
  - 提供 RESTful API 接口，管理用户与植物状态数据；
  - 安全验证、权限控制；
- **数据库模型简要**：
  - 用户表（User）
  - 设备表（Device）
  - 传感数据表（PlantData）
  - 灌溉记录表（IrrigationLog）

## 四、数据流设计

### 4.1 数据流动方向

```
传感器 → STM32 → ESP32 → 服务器/树莓派 → 决策 → 控制信号 → ESP32 → STM32 → 水泵
```

### 4.2 数据包格式（示例）

- **上传数据帧（ESP32 → Server）**

```
{
  "device_id": "plant001",
  "temperature": 26.4,
  "humidity": 48.1,
  "soil_moisture": 23.7,
  "light": 1030,
  "water_level": "low",
  "battery": 76,
  "timestamp": "2025-06-13T13:01:22"
}
```

- **策略反馈帧（树莓派 → ESP32）**

```
{
  "device_id": "plant001",
  "threshold": {
    "min_moisture": 20,
    "max_moisture": 40
  },
  "strategy_id": "rl-0529v2"
}
```

## 五、交互流程图（简要文字描述）

### 5.1 用户手动控制流程

1. 用户登录 Web 系统，访问设备控制界面；
2. 点击“浇水”按钮，Web 前端调用控制接口；
3. 后端将指令存入队列并推送至 ESP32；
4. ESP32 接收到控制信号，通过串口传递至 STM32；
5. STM32 控制水泵动作，完成一次灌溉；
6. ESP32 将此次操作记录同步至服务器。

### 5.2 AI 自动决策流程

1. ESP32 定时上传环境数据至树莓派；
2. 树莓派通过模型推理生成最新阈值策略；
3. 将策略通过 JSON 反馈至 ESP32；
4. 若 soil_moisture < threshold.min_moisture，ESP32 发起浇水命令；
5. 浇水记录同步至后端。

## 六、系统设计原则与约束

- 模块间低耦合、高内聚；
- 所有通信均使用 JSON 封装，易于解析与扩展；
- 每个功能模块具备独立可测试性；
- 模型参数可热更新，不影响系统运行；
- 所有设备支持断电重启后自恢复逻辑；

## 七、系统设计总结

本系统采用分层解耦、多模块协作的软硬件联合架构，融合边缘计算、IoT感知与AI决策机制，确保在成本受控的同时实现灌溉行为的高智能化。设计方案充分考虑工程可行性与学术前沿的融合，具备良好的拓展性、移植性与展示价值，为后续工程开发与论文撰写奠定坚实基础。
