# 智慧植物灌溉与监控系统项目立项书

## 一、项目概述

### 1.1 项目背景

随着智慧农业、城市园艺与家庭绿植需求的不断增长，传统的人工灌溉方式已无法满足人们对高效、低耗、精准植物养护的需求。近年来，物联网（IoT）与人工智能（AI）技术的融合推动了“软硬结合”式植物养护系统的广泛探索。智能灌溉系统通过集成传感器、控制器与数据处理平台，实现环境感知、数据驱动决策与动态控制，已成为智慧农业的重要发展方向。

本项目聚焦于面向家庭园艺、温室种植及中小型农场应用场景，设计一套融合强化学习的智能灌溉与环境监测系统。项目综合应用嵌入式系统（STM32、ESP32）、边缘计算（Raspberry Pi）、强化学习（RL）与 Web 前后端开发技术，实现软硬件协同、数据驱动控制与多模态人机交互。

### 1.2 项目目标

本项目旨在构建一个模块化、可拓展、高鲁棒性的智能植物灌溉系统，满足以下目标：

- 实现多维环境参数（温湿度、土壤湿度、光照、水位、电量）实时采集与数据融合；
- 基于强化学习算法优化植物个体的灌溉阈值与控制策略，实现动态学习与行为调整；
- 提供语音交互、OLED 显示、LED 灯带状态反馈等本地多模态交互能力；
- 支持数据可视化、远程控制、用户管理等基于 Web 平台的交互功能；
- 完成完整的软件工程生命周期文档（需求分析、系统设计、模块开发、系统测试、部署集成与总结）。

## 二、系统构成与分工

| 模块    | 技术栈                       | 功能职责                                     |
| ------- | ---------------------------- | -------------------------------------------- |
| STM32   | C/C++ + HAL                  | 底层传感器驱动与数据采集、水泵控制、命令响应 |
| ESP32   | C++ / Arduino / FreeRTOS     | 数据打包转发、状态管理、OLED/LED/语音交互    |
| 树莓派  | Python + PyTorch             | 数据存储与分析、RL模型训练与策略推送         |
| Web前端 | Vue.js / Bootstrap / ECharts | 数据展示、模式切换、社区互动界面             |
| Web后端 | Flask / RESTful API / MySQL  | 数据服务、权限管理、AI推荐接口               |

## 三、关键技术与创新点

### 3.1 强化学习灌溉策略生成

通过构建状态空间（环境参数向量）、动作空间（阈值调整、是否灌溉）与奖励函数（水资源节约、植物湿度维持度），构建 DQN 类强化学习模型，基于实际运行数据持续优化灌溉决策策略。

### 3.2 多模态本地交互机制

设计包含按钮触发、语音交互（关键词唤醒 + AI对话）、OLED图形界面与LED可视反馈的本地用户交互系统，实现本地控制、模式切换与人机情感交互。

### 3.3 全链路分层结构与模块解耦

从传感层（STM32）到交互层（ESP32）再到学习层（树莓派）及服务层（Web），构建四层分工明确、通信规范清晰的模块化架构，支持横向扩展（多植物节点）与纵向优化（模型替换、服务迁移）。

### 3.4 Web门户与社区融合平台

开发集“植物数据监控中心 + 用户个性主页 + 植物社区论坛 + AI养护推荐”为一体的前端交互平台，提升项目可视化、参与性与学术传播能力。
