## ESP32 中继与交互模块（详细设计）

### 3.1 模块定位

ESP32 模块位于系统结构的中间层，承担与 STM32 的底层数据通信、中间数据解析处理与上传、状态显示（OLED、LED）、语音交互管理、远程控制接收与转发等职责，是系统的边缘感知与人机交互中枢。

### 3.2 硬件与接口说明

- UART 接口（连接 STM32）
- OLED 显示屏（I2C）
- WS2812 灯带（单线 GPIO）
- 麦克风模块（I2S 或模拟输入）
- 按键（本地模式切换）
- ESP-NOW/WIFI（连接路由器/服务器）

### 3.3 功能子模块划分

| 子模块       | 职责                     | 描述                       |
| ------------ | ------------------------ | -------------------------- |
| 串口监听任务 | 接收 STM32 上传数据      | 并转发至服务器和树莓派     |
| 控制命令接收 | 接收平台命令并转发 STM32 | 包括灌溉、阈值设置等       |
| 显示管理     | OLED 状态轮播、图标更新  | 基于系统模式变化刷新屏幕   |
| LED 状态指示 | 根据状态变化显示颜色     | 电量、浇水、异常等多种状态 |
| 语音管理     | 录音+命令识别+AI对话     | 联动本地逻辑与云端接口     |

### 3.4 多任务调度逻辑（FreeRTOS）

- `UartTask`：循环接收 STM32 的数据 → 入 JSON 队列
- `UploadTask`：定时取出 JSON → 封包上传 HTTP/MQTT
- `OLEDTask`：根据模式轮询切换显示内容（默认、灌溉、语音）
- `LEDTask`：根据 soil、battery 状态控制 RGB 编码
- `VoiceTask`：监听按钮或语音唤醒词，激活录音与处理逻辑

### 3.5 状态机（工作模式切换）

```
[default] --(voice/button)--> [watering]
   |                              |
   +--------<-- timeout ----------+
   |
   +--------(low battery)-------> [low_power]
```

### 3.6 通信数据格式（示例 JSON）

```
{
  "device_id": "esp32-a01",
  "status": "watering",
  "voice_mode": true,
  "threshold": {
    "min_moisture": 20,
    "max_moisture": 40
  },
  "relay_status": "on"
}
```

### 3.7 异常与调试机制

| 异常类型           | 响应策略        | LED 指示   |
| ------------------ | --------------- | ---------- |
| 无法连接 WIFI      | 自动重连（3次） | 蓝色闪烁   |
| 接收 JSON 解析失败 | 丢弃并记录日志  | 红灯短闪   |
| 与 STM32 通信超时  | 重启串口模块    | 黄色持续亮 |

### 3.8 可测试性说明

- 使用串口助手模拟上位机调试数据流动
- 模拟按钮事件触发不同工作模式，观察 OLED、LED 是否变化正确
- 打印系统日志、上传日志、出错记录
- 在 Voice 模块中测试唤醒与异常退出情况
