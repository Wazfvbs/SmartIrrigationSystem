## 树莓派 AI 控制模块

### 4.1 模块定位

树莓派作为本系统中的边缘智能中心，运行 PPO 强化学习模型，根据环境状态数据生成最优灌溉策略，并通过无线通信将阈值或控制指令反馈至 ESP32 模块。该模块的设计需兼顾实时性、学习能力与模型可解释性。

### 4.2 算法结构

采用近端策略优化算法（Proximal Policy Optimization, PPO），基于策略梯度方法构建 Actor-Critic 网络架构：

- **Actor 网络**：根据当前状态输出连续浇水量（0~1）
- **Critic 网络**：评估当前策略下状态的长期收益（Value Function）

模型部署结构如下：

```
状态输入 → 策略网络（Actor） → 浇水量预测 → 策略阈值转换
                     ↓
              价值网络（Critic） → 更新信号
```

### 4.3 状态空间设计（State Space）

| 状态变量        | 含义               | 取值范围   |
| --------------- | ------------------ | ---------- |
| soil_moisture   | 当前土壤湿度       | [0.0, 1.0] |
| temperature     | 空气温度           | [10, 45] ℃ |
| humidity        | 空气湿度           | [0, 100]%  |
| light_intensity | 光照强度（归一化） | [0.0, 1.0] |
| co2_level       | CO₂ 浓度（模拟）   | ppm, float |
| growth_stage    | 植物生长进度       | [0.0, 1.0] |

状态向量为 6 维连续变量，输入策略网络。

### 4.4 动作空间（Action Space）

动作为连续浇水量：

```
Action ∈ [0.0, 1.0]  // 表示相对最大浇水量（如200ml）
```

### 4.5 奖励函数设计

```
Reward = α * Growth_Reward + β * Moisture_Reward - γ * Water_Penalty
```

- Growth_Reward：与生长速度成正比
- Moisture_Reward：土壤湿度处于 [0.4, 0.6] 区间获得正奖
- Water_Penalty：每单位水施加惩罚以控制资源浪费

超参数示例：α=1.0，β=0.6，γ=0.2

### 4.6 策略输出与下发

策略输出形式：

```
{
  "strategy_id": "ppo-v3.2-202506",
  "threshold": {
    "min_moisture": 0.38,
    "max_moisture": 0.62
  },
  "confidence": 0.91
}
```

ESP32 接收到该策略后用于动态更新本地判断逻辑。

### 4.7 模型训练与部署流程

1. 收集历史数据（湿度、光照、灌溉记录、植物状态）
2. 构造模拟环境（Gym-like）
3. 使用 PPO 训练智能体
4. 导出模型权重 `.pt/.onnx` 文件
5. 树莓派部署推理引擎（如 PyTorch、ONNXRuntime）
6. 每日定时推理 → 输出阈值 → 发回 ESP32

### 4.8 模型更新与版本控制

| 字段        | 描述                         |
| ----------- | ---------------------------- |
| strategy_id | 模型版本编号（自动生成）     |
| train_date  | 最近训练时间                 |
| performance | 策略成功率评估               |
| reward_mean | 平均奖励值（跨episode）      |
| file        | 模型路径（如 model_v3.2.pt） |

所有策略输出需绑定 metadata，可回溯。

### 4.9 异常与安全处理

- 若模型输出超出物理可行范围（如阈值 > 1.0）→ 回滚至默认策略
- 若连续多次无法完成模型推理 → 自动关闭 AI 接口，转为手动/规则控制
- 日志记录所有推理请求、输出、奖励与执行效果（JSON + CSV）

### 4.10 可测试性说明

- 使用仿真环境验证训练策略的稳定性与收敛性
- 使用历史数据复现实际推理流程，校验策略效果
- 所有策略下发结果需可视化呈现（图表+日志）
