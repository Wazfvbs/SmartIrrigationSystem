# docs/ 目录说明文档（README）

> 本文档用于说明智慧植物灌溉系统文档仓库结构及内容使用建议，适用于开发者、评审人员、项目协作者。

---

## 📂 文档目录结构

```bash
/docs
├── 01_项目立项书.md               # 项目背景与目标定义
├── 02_软件需求规格说明书（SRS）.md # 功能、性能与接口需求
├── 03_系统设计说明书（SDS）.md     # 架构、模块划分与数据流程
├── 04_模块详细设计说明书.md       # STM32、ESP32、树莓派等子模块详解
├── 05_系统测试说明书.md           # 黑盒/白盒测试用例与结果
├── 06_用户使用手册.md             # 操作指引与常见问题解答
├── 07_部署与运维手册.md           # 部署步骤、版本管理、维护策略
├── README.md                      # 当前文档说明文件
└── 各子模块设计说明书/             # 子模块拆分设计（可选）
```

---

## 📄 文档内容索引与说明

| 编号 | 文档名称           | 说明                                        |
| ---- | ------------------ | ------------------------------------------- |
| 01   | 项目立项书         | 阐述系统背景、意义、建设目标与实施计划      |
| 02   | 软件需求规格说明书 | 明确用户需求、系统边界、接口要求等内容      |
| 03   | 系统设计说明书     | 系统架构图、数据流、功能模块分解说明        |
| 04   | 模块详细设计说明书 | 包含 STM32、ESP32、AI模块、前后端子系统说明 |
| 05   | 系统测试说明书     | 包括测试用例、指标、流程、日志与判定标准    |
| 06   | 用户使用手册       | 面向终端用户，提供完整使用路径与操作指导    |
| 07   | 部署与运维手册     | 给出部署流程、远程访问、OTA升级等运维策略   |

## ✅ 使用建议

- 建议文档依照编号顺序进行阅读；
- 所有 `.md` 文件支持 GitHub 在线预览与 Typora 编辑；
- 建议以 PDF 格式导出后用于项目评审或成果展示；
- 所有技术资料请统一保存在 `docs/`，并同步更新项目根目录下的 `README.md`。
